# Вход и регистрация

Формы находятся в `/index.html#/login` и `/index.html#/register`.
Регистрация требует email и пароль от 8 до 128 символов и сразу выполняет вход.
Подтверждение email, телефона и второй фактор для новых аккаунтов не требуются.
Существующие аккаунты также могут входить без подтверждения email.

Пользователи и хеши паролей хранятся в существующих таблицах ASP.NET Identity.
Миграция схемы для этого изменения не нужна. Рабочие аккаунты для проверки
не создавались: HTTP-тесты и браузерная проверка использовали отдельные базы.

## API

| Метод | Адрес | Назначение |
| --- | --- | --- |
| GET | `/api/auth/csrf` | Получить `{ token }` и служебную cookie |
| POST | `/api/auth/register` | `{ email, password }`, создать аккаунт и войти |
| POST | `/api/auth/login` | `{ email, password, rememberMe }`, войти |
| GET | `/api/auth/me` | Получить `{ id, email }` текущего пользователя |
| POST | `/api/auth/logout` | Завершить сессию |

API товаров, логистических точек и рейсов требуют входа. Без сессии возвращается
`401`, без перенаправления на HTML. Статические файлы и корневой адрес `/`
с описанием API доступны без входа.

Авторизация работает через cookie `Logistics.Auth` с `HttpOnly` и `SameSite=Lax`.
При HTTPS cookie получает флаг Secure. Без `rememberMe` cookie действует в рамках
сессии браузера; с ним сохраняется между запусками. Срок билета — 7 дней со
скользящим продлением. Пароли и билеты входа не сохраняются в localStorage.
Пять неверных паролей временно блокируют вход на 5 минут.

Для POST/PATCH/PUT/DELETE к защищённым контроллерам и для входа/регистрации
нужно сначала получить CSRF-токен и передать его в заголовке `X-CSRF-TOKEN`.
Запросы должны использовать одну cookie-сессию. После входа или выхода токен
нужно получить заново, поскольку он связан с текущим пользователем.
Фронт получает свежий токен перед каждым запросом входа, регистрации и выхода.

В этой версии все вошедшие пользователи имеют одинаковый доступ к справочникам
и рейсам. Отдельные роли и разграничение по владельцу не добавлялись.

